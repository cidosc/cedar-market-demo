# Cedar · 松间卡集演示

独立的 Next.js App Router 商城展示，复用卡片堆叠、交换与悬浮效果组件，以及商品舞台、购买入口和独立结账结构。采用暖白、铜金与墨色的新配色。支持中、英、日、韩路径与商品文案；部分辅助说明以英语提供。

所有商品、标价和订单均为合成演示。真实支付、账号交付、库存、邮件、客服与外部服务的实现和依赖均未复制。结账使用固定演示访客，不收集真实邮箱、账号或付款资料；客服页只显示固定的本地回复。

## 运行

需要 Node.js 22+ 和 npm，无需数据库、商户密钥或环境秘密。

```sh
npm ci
npm run build
npm start
```

访问 http://127.0.0.1:3101 。开发可运行 `npm run dev`，类型检查为 `npm run check`。本项目没有部署工作流。

## 模拟购买

选择主题卡 → 核对结账 → 创建模拟订单 → 点击“模拟付款” → 点击“模拟交付” → 下载本地 TXT 示例。订单只存于当前本地服务器进程，重启后清空；浏览器只记住最后一个模拟订单编号，不作为真实业务存储。
